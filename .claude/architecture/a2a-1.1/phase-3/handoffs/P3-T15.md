## Scope delivered (claims for the reviewer to verify)

New package-visible/public types in `client/base/.../client/`:
- `ClientTaskReducer` (package-private, pure, synchronized, no I/O, no network recovery, no server
  generation allocation).
- Public immutable `TaskView(task?, sync, throughGeneration?, history, timeline)`, `ViewSync`
  (`NO_BASELINE|SYNCHRONIZED|INCOMPLETE`) and `HistoryCoverage(requestedLimit?, returnedRange?, flags)` with
  flags `WINDOW_ONLY|LEGACY_GAPS|UNKNOWN_SKIPPED|NOT_ASSERTED` (no FULL flag).
- `ClientTaskManager` is untouched; its existing `ClientTaskManagerTest` (14 tests) still passes.

Reducer rules implemented: snapshot replaces windows (limits independent; zero/finite/null);
contiguous known updates advance the watermark only after reduction; stale/duplicate events never
re-append history/chunks; gap or uncertainty freezes the last safely interpreted task (`through` stays);
unknown kinds with known generations are accounted for sequence (no false gap) but mark
`UNKNOWN_SKIPPED`/INCOMPLETE; unknown frames without generation can leave a real gap; generation 0 or
consecutive equal event generations taint reliability permanently (snapshots never reset; read snapshots are
not stream events); metadata-only status with same message identity is not a new history occurrence;
`LEGACY_GAPS` only through an explicit `recordLegacyGaps()` call; direct Message yields no Task baseline.
