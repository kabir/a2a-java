## Actionable findings

1. **P2 — public unary `sendMessage` bypasses selected-1.1 decoding.** `client/transport/grpc/src/main/java/org/a2aproject/sdk/client/transport/grpc/GrpcTransport.java:496-503` maps the Task with `FromProto.task` regardless of selected version. `client/base/src/main/java/org/a2aproject/sdk/client/Client.java:329-336` still calls this method for ordinary nonstreaming public `sendMessage`. A valid 1.1 Task response containing known timeline entries at 7 and 9 around future oneof bytes at 8 therefore throws: `TimelineEntryMapper.java:34` rejects `ENTRY_NOT_SET`. The new `sendInput` path correctly uses `decodeSendResponse`, but does not repair this existing public entry point. This violates T6's selected-version known/unknown policy and task-bearing send decoding requirement. Use the versioned send decoder for selected 1.1 while retaining explicit 1.0 behavior; add a real public unary `Client.sendMessage` peer case using that timeline, plus malformed-known rejection. The analogous direct `GrpcTransport.getTask` at line 549 also retains bare mapping, although public `Client.getTask` correctly selects `getTaskDecoded`.

2. **P2 — explicit 1.0 list pagination contract changes.** `GrpcTransport.java:588` replaces the former manual result mapping with `FromProto.listTasksResult`. The old transport returned `null` for an empty next-page token and used the returned task count for `pageSize`. `spec-grpc/src/main/java/org/a2aproject/sdk/grpc/mapper/ListTasksResultMapper.java:28-29` instead retains the protobuf empty string and maps the wire `pageSize`. The inspected generated mapper confirms both assignments (`spec-grpc/target/generated-sources/annotations/org/a2aproject/sdk/grpc/mapper/ListTasksResultMapperImpl.java:49-54`). For a final page with two tasks, absent token and absent wire page size, an explicit-1.0 public list now returns token `""` and page size 0 instead of `null` and 2. Callers using null as end-of-pagination evidence can request an extra/repeated first page. Preserve the historical 1.0 normalization in this transport and test both a final page and a wire page size differing from returned count. Requirement: immutable explicit-1.0 contract; T6 pagination preservation. No finding is made that this older normalization is the preferred new-version protocol design.

3. **P2 — opening deadline can lose cancellation before observer installation.** `GrpcTransport.java:403-423` creates the deadline-bearing observation before publishing its observer reference. A legal interleaving with an expired/near-expired `SpiCallOptions.openingDeadline` is: the timer finishes the observation and runs its cancel action at lines 408-415 while `observerReference` is null; the method then installs the observer and unconditionally starts the RPC. `TransportObservation.java:188-198` has already consumed its one-shot detach. `EventStreamObserver.java:50-58` only checks its own cancellation flag, which was never set. The caller sees DEADLINE while a held-open RPC remains attached until channel close; completed observations are removed from the active set. Preserve cancellation intent independently of observer installation and ensure a late start is cancelled or prevented. Add a bounded deterministic deadline-before-install/start test and assert underlying cancellation, one terminal and no leaked read. Requirement: T5/T6 opening-deadline, cancellation and resource ownership contract. This concerns a source-visible interleaving; no timing-sensitive runtime reproduction was attempted.

4. **P2 — required public gRPC lifecycle/race evidence is absent.** `client/base/src/test/java/org/a2aproject/sdk/client/Phase2GrpcPublicClientTest.java:40-108` contains one real `Client.builder` test: explicit 1.1 GET and a normal Task/message-update/future/completion stream. It does not exercise the required completion/error/close race, malformed-known public terminal, all-unknown public close, or closing one of two public clients. Those close/isolation cases in `client/transport/grpc/src/test/java/org/a2aproject/sdk/client/transport/grpc/Phase2PublicClientTest.java:186-235` instantiate `GrpcTransport`, not public `Client`; the finite-demand case at lines 239-298 also uses raw SPI. `EventStreamObserverTest` tests local rejection and malformed decoding without a real call. Existing `GrpcOwnedLifecycleTest` exercises transport ownership, and the shared adapter's saved race evidence is useful but does not replace T6's explicit per-binding public race gate. Add bounded real public gRPC cases, including a held callback while peer completion/error and close compete, and assert exactly one terminal and no later callback starts. Also cover public default selection and explicit-1.0 local rejection, public unary/direct Message and list behavior, and guard/artifact/mismatch behavior through `Client`, rather than relying exclusively on transport peer cases. Requirement: T6 per-binding public controlled-peer bullets; A04/A07/A09/A10 as scoped to Phase 2. This finding does not assert that all these untested behaviors are broken.

## Correction re-review — 2026-11-16

**Current disposition: accepted with nonblocking follow-ups; ready for the developer to assign T7.** All four original P2 findings are closed within T6c scope. ### Nonblocking evidence follow-up

Strengthen `Phase2GrpcPublicClientTest.java:419-493` when next extending lifecycle coverage: the race workers wait on `raceStart`, but the main thread releases the held callback immediately after releasing those workers. Scheduling can therefore let the callback finish before either terminal action reaches the transport. Also only one event is sent, so the late-callback counter is not challenged by a queued second event; the competing peer action is completion, with malformed/error behavior covered separately. Stage a terminal attempt while the callback remains held and add a pending update/error variation. This is a limitation of the new race test's deterministic overlap, not evidence of a production ordering defect. The real public completion/close race now exists and checks one terminal, and the unchanged shared adapter's prior deterministic held-callback failure/cancel tests plus its serialized observation path supply complementary ordering evidence. This follow-up does not block T7.

### Closure evidence

1. **Unary decode — closed.** `GrpcTransport.java:503-514` selects `StreamDecoder.decodeSendResponse` for a selected-1.1 Task; explicit 1.0 still maps through the old path. Direct GET at `:562-570` similarly selects `decodeTask`. IllegalArgumentException from malformed known Task content is wrapped in `A2AClientException`. `Phase2GrpcPublicClientTest.java:178-231` calls real nonstreaming public `Client.sendMessage` against a Netty gRPC peer and asserts known timeline entries around the skipped future entry, a direct Message, malformed-known rejection and exactly three sends. The transport peer additionally calls the direct legacy-signature GET with the future timeline. These paths repair the concrete bypass identified in finding 1 without changing the selected version.

2. **Explicit-1.0 pagination — closed.** `GrpcTransport.java:609-613` restores the manual task-count page size and empty-token-to-null mapping only for the legacy branch. `Phase2PublicClientTest.java:319-326` asserts final-page null token and returned count, including a wire page size different from the count. Selected 1.1 keeps the decoded list path and its per-task evidence.

3. **Startup cancellation — closed.** `GrpcTransport.java:407-426` allocates cancellation intent before creating the observation, sets it even if no observer exists, passes the same AtomicBoolean to the observer and prevents startup when cancellation is already known. If cancellation occurs after the pre-start check, `EventStreamObserver.java:48-67` uses that shared flag in `beforeStart`; if startup has already installed the call, cancellation directly reaches it. Thus the originally lost intent survives all three orderings. `EventStreamObserverTest.java:51-123` forces a deadline before observer construction, then installs a call double and checks cancellation and a single deadline terminal. This is a deterministic seam test, not an end-to-end scheduler test of the private factory; the factory wiring was independently inspected.

4. **Public evidence — closed, with race-test strengthening above.** The real `Client.builder` suite grew from one to seven tests. It covers default selected 1.1 GET/list and explicit-1.0 zero-I/O advanced-input rejection (`:64-118`), artifact-only input and typed guarded mismatch (`:121-175`), ordinary unary Task/direct Message/malformed Task (`:178-231`), known streaming callbacks and unknown skip (`:234-301`), all-unknown public close plus a second client remaining usable (`:304-373`), malformed-known public stream cancellation with one error and zero events (`:376-416`), and public completion/close racing (`:419-493`).
